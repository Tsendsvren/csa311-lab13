# PROJECT.md - Mini Library System

## Сонгосон сэдэв
**Mini Library** - номын сан удирдлагын систем

## Товч тодорхойлолт
Жижиг номын санд зориулсан backend API + хялбар frontend. Номын бүртгэл, гишүүн, удирдлага, түрээсийн хяналт хийх боломжтой веб программ.

## Scope (Хамрах хүрээ)

### Хийх зүйлс
- **Book, Inventory** - ном нэмэх, засах, устгах, хайх (ISBN, нэр, зохиолч, төрөл)
- **Member Management** - гишүүн бүртгэх, засах, идвэхгүй болгох
- **Loan Tracking** - ном түрээслэх, буцаах, хугацаа хэтэрсэн мэдээлэл
- **Dashboard** - статистик (нийт ном, гишүүн, одоогийн түрээс, хугацаа хэтэрсэн)
- **Search & Filter** - ном болон гишүүнээр хайх

### Хийхгүй зүйлс
- Хэрэглэгч нэврэх / authentication
- Email мэдэгдэл
- Олон номын сан

## Техникийн мэдээлэл
- **Backend**: Node.js + Express + TypeScript
- **Database**: SQLite (better-sqlite3) - хэрэглэхэд хялбар, суулгахгүйгээр ажилна
- **Frontend**: Vanilla HTML + CSS + JS (хэрэглэгчийн интерфэйс)
- **Testing**: Jest + supertest
- **API**: RESTful, JSON


## Үндсэн Feature-үүд (3+)
1. **Book CRUD** — бүрэн CRUD + хайх/шүүх
2. **Member CRUD** — бүрэн CRUD + идэвхтэй/идэвхгүй статус
3. **Loan System** — зээлэх, буцаах, хугацаа хянах
4. **Dashboard API** — нэгдсэн статистик
5. **Search** — ном болон гишүүнээр хайх
